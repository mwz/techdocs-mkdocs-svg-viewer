# Security policy

## Supported versions

Security fixes are released for the latest published version only.

## Report a vulnerability

Do not open a public issue for a security problem. Report it privately with
[GitHub private vulnerability reporting](https://github.com/mwz/techdocs-mkdocs-svg-viewer/security/advisories/new).

Include the affected version, the steps to reproduce the problem and its
possible effect. You will get a reply when the report has been reviewed.
